
# Animatch

![pokemon-banner](<img src="/pokemon-banner.gif" alt="pokemon-banner" width="200"/>)
Anime suggestions generator made with React + Vite based on the 2024 project made for the Diploma in IT. 
The website is deployed on netlify and to use it click on the following link [Animatch deployed site](https://animatchgenerator.netlify.app/)

This time, I wanted to make things easier and available for users so I remove the sign up and log in process, there's only the discovery page.
